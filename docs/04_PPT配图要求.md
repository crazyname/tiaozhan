# 青韵智控 PPT 配图与视觉执行说明

> 本文件不再单独维护页序和版式细节。
>
> **正式唯一锁定版本：** [`submission/04_路演PPT/路演PPT_17页结构与文案.md`](../submission/04_路演PPT/路演PPT_17页结构与文案.md)

当前配图与视觉执行只保留以下原则：

## 1. 图片优先级

1. 团队真实样机
2. 真实实验现场
3. 真实数据图
4. 茶厂 / 合作社真实应用
5. 团队自绘技术图
6. 论文 / 专利 / 官方资料证据
7. 高质量场景素材
8. 装饰性图片

越接近正式比赛，越减少第 7、8 类素材。

## 2. 视觉风格

- 科研竞赛答辩 × 茶产业视觉识别
- 白色 / 极浅灰绿背景
- 单一茶绿色体系：`#145A32`、`#2E8B57`、`#DDEFE4`、`#F7FBF8`
- 正文深灰：`#2F3A35`
- 正文页顶部只保留轻量导航，与正文自然连接
- 目录页不重复顶部导航
- 主要使用编号、细线、分栏、流程图、矩阵、数据图和实拍图片
- 不使用大面积卡片堆叠、框中框、手帐风、海报风、霓虹、玻璃拟态和复杂 3D
- 茶山、茶园、竹筛仅作为弱背景或局部识别元素，不抢正文

## 3. 真实证据原则

- 没有真实样机照片时，用明确标注的“待替换”占位，不用 AI 图冒充实物
- 没有真实响应曲线时，不画成实验结果
- 没有 A/B/C 数据时，不制作“提升 xx%”图表
- 市场、客户、营收、订单、合作等信息必须有可核验来源

## 4. 数据图规范

- 折线图：MOS 响应、失水率、叶温、综合状态指数
- 柱状图 / 箱线图：A/B/C 组品质、批次波动、人工干预、成本 / 能耗
- 矩阵 / 表格：技术边界、方案对比、竞品、研发状态
- 全部使用同一绿色体系，关键节点可用深茶绿竖线或浅绿阴影标记

## 5. 最终原则

> **照片负责真实，图表负责解释，实物负责可信，数据负责证明。**

所有逐页配图位置、页面内容和格式，以正式 17 页锁定文件为准。
