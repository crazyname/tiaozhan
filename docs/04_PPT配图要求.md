# 青韵智控 PPT 配图要求（按官方汇报模板适配）

本文件与 `03_PPT结构思路.md` 同步，适用于按第十五届“挑战杯”中国大学生创业计划竞赛官方汇报模板制作的 18 页版本。

官方模板强调“简洁、实用、清晰”，不追求过度视觉化。因此，本项目配图的首要目标不是“好看”，而是**证明项目真实、解释技术、支撑结论**。

---

## 1. 图片优先级

正式赛稿优先级固定为：

1. 团队真实样机照片；
2. 真实实验现场；
3. 真实数据图；
4. 茶厂 / 合作社真实应用；
5. 自绘技术结构图；
6. 论文 / 专利 / 官方资料证据；
7. 高质量场景素材；
8. 装饰性图片。

越接近正式比赛，越要减少第 7、8 类素材。

---

## 2. 统一视觉方向

主题：**传统制茶场景 + 现代感知控制技术**。

配色建议：

- 主色：浅茶绿；
- 强调：深茶绿；
- 辅助：米白、木色、灰绿；
- 少量暖金 / 橙色：做青关键节点；
- 红色：仅用于风险、缺口、警示。

禁止：

- 高饱和荧光绿；
- 大面积科技蓝 / 紫色霓虹；
- 复杂 3D 渲染；
- 无意义芯片、AI 大脑、数据粒子背景；
- 把论文截图和网页截图直接铺满页面。

---

# 3. P1–P18 配图要求

## P1｜封面

主视觉：高质量凤凰单丛茶园 / 制茶场景 / 鲜叶。

要求：

- 有明显茶产业属性；
- 主体尽量位于一侧，为标题留负空间；
- 正式赛稿最好替换为团队在真实茶园 / 茶厂拍摄的照片；
- 不使用明显 AI 生成痕迹的人物图。

---

# 一、项目背景

## P2｜真实痛点

必须优先使用真实场景：

- 制茶师傅做青判断；
- 摇青滚筒 / 竹筛；
- 凤凰单丛加工现场。

建议组合：

左侧 1 张真实场景大图，右侧 3 个痛点。

如果已有访谈，优先加入：

- 师傅原话摘要；
- 茶厂采访照片；
- 当前工艺记录表 / 人工判断节点。

## P3｜已有方案与技术缺口

以“证据型对比图”为主，不以场景照片为主。

建议：

- 2–3 个已有研究 / 设备缩略证据；
- 中间做已有能力矩阵；
- 右侧突出本项目待突破部分。

每个外部图片 / 论文图必须记录来源。

---

# 二、项目概述

## P4｜总体系统架构

必须自绘统一闭环图：

鲜叶 → 多模态感知 → 状态估计 → 工艺决策 → 执行 → 品质反馈。

要求：

- 使用同一绿色体系；
- 箭头和层级清晰；
- 不用 3D 图标；
- 这是全套 PPT 的核心总图。

## P5｜作品形态与当前进度

最终必须以真实样机为主图。

建议视觉：

- 左：样机 / 模块实拍；
- 右：模块标注；
- 下：当前完成度时间线。

可展示：

- 电子鼻阵列；
- 气泵、电磁阀与采样气路；
- RGB 相机；
- 称重模块；
- STM32 / ESP32；
- 小型滚筒；
- 上位机界面。

所有未完成内容标注“待研发 / 待集成 / 待验证”。

---

# 三、项目优势

## P6｜多模态状态表征

建议用信息图，不需要照片堆叠。

四类输入：

- VOC；
- RGB；
- 失水；
- 叶温 / 环境。

中心：鲜叶状态。

底部说明不同模态分别反映什么变化。

## P7｜电子鼻稳定在线采样

最佳组合：

- 左：真实电子鼻 / PCB；
- 中：采样—吸附—清洗气路图；
- 右：真实 MOS 响应曲线。

后期必须用真实曲线替换示意曲线。

## P8｜固定控制 vs 状态驱动控制

使用左右对比图：

左：固定时刻 / 固定参数；

右：实时状态 → 判断 → 动态时机 / 强度 / 持续时间。

中央只保留一个核心箭头：

**Time-based → State-based**

不需要照片。

## P9｜竞品 / 文献能力矩阵

以表格或矩阵为主。

可加入少量：

- 自动做青设备照片；
- 电子鼻论文图；
- 机器视觉研究图。

但外部图片只作为“证据锚点”，不能抢矩阵主体。

---

# 四、项目应用

## P10｜分阶段验证路径

用三级阶梯 / 路线图：

在线监测 → 人工确认半自动 → 自适应闭环。

无需照片，除非已有真实样机进度照。

## P11｜三组对照实验

必须用清晰实验设计图：

A：老师傅传统做青  
B：固定程序自动做青  
C：状态驱动自适应做青

后期逐步补入：

- 三组实验现场；
- 三组成茶实物；
- 感官审评照片；
- GC-MS / 理化测试；
- 真实统计图。

严禁在尚无实验数据时制作“示意准确率”“示意提升百分比”。

## P12｜应用 / 小试 / 中试证据

这页正式比赛必须以真实证据为主。

优先顺序：

1. 茶厂现场试用；
2. 合作社 / 企业应用照片；
3. 设备运行记录；
4. 师傅 / 企业反馈；
5. 应用证明 / 合作意向；
6. 连续批次数据。

项目当前阶段若没有这些材料，页面中只保留“证据待补充”占位，不使用素材图冒充应用现场。

# 五、社会价值

## P13｜经验数字化与产业价值

推荐双路径图：

传统：经验 → 个人 → 难复制  
数字：经验 + 数据 → 状态模型 → 工艺档案 → 可复用

如果有真实师傅合作，可加入 1 张小图增强可信度。

不要用大段“乡村振兴”口号替代具体价值。

# 六、商业模式

## P14｜目标客户与场景

建议使用 4 类客户场景卡：

- 茶企；
- 合作社；
- 现有摇青设备改造客户；
- 科研 / 教学机构。

正式赛稿优先使用真实客户访谈照片或调研记录，不使用纯图标替代全部内容。

## P15｜商业路径与财务验证

以商业闭环图 + 成本结构为主。

当前阶段可展示“待验证假设”：

设备销售 / 数字化改造 / 软件与维护服务 / 实验平台。

后续必须补：

- BOM；
- 样机成本；
- 目标售价依据；
- 运维成本；
- 客户付费意愿；
- 毛利 / 现金流等测算依据。

所有商业数字必须能追溯来源或计算过程。

---

# 七、团队介绍

## P16｜团队能力闭环

推荐中心项目 + 外围能力模块：

硬件 / 算法 / 控制 / 茶学 / 产业。

优先加入：

- 团队真实工作照；
- 代表性项目 / 竞赛成果；
- 每人职责；
- 指导教师 / 顾问专业支撑。

不要做大面积证件照墙。

---

# 八、未来展望

## P17｜一年 / 三年路线、融资与风险

建议做“上：时间轴；下：风险矩阵”的结构。

一年：样机、数据、对照实验、试点。  
三年：跨茶季 / 多品种、模块化产品、更多真实应用。

风险至少覆盖：

- 技术；
- 市场；
- 供应链；
- 工艺安全。

融资、营收和团队规模如果没有依据，只标“待评估 / 待验证”。

---

## P18｜封底

与 P1 使用同源主视觉。

# 6. 数据图规范

所有图表统一绿色体系，但可读性优先。

### 折线图

用于：VOC、失水率、叶温、综合状态指数。

关键摇青时刻使用竖线或淡色区域标记。

### 柱状图

用于：A/B/C 三组品质、人工干预、能耗、成本、批次波动。

### 箱线图 / 误差棒

正式实验结果建议优先使用，用于展示批次稳定性和统计差异。

### 混淆矩阵

只在阶段识别模型完成真实验证后使用。

### 财务图

只有在成本、售价、收入、现金流假设有明确依据后才能进入正式赛稿。

---

# 7. 最终视觉判断标准

正式 PPT 中每张图都应该回答至少一个问题：

- 这个问题真的存在吗？
- 你们真的做出了东西吗？
- 这个技术为什么有效？
- 实验是否公平？
- 数据是否支持结论？
- 是否有人愿意使用？
- 商业数字是否可信？

如果一张图只回答“这一页看起来更好看”，它通常不应该进入正式赛稿。

最终原则：

> **照片负责真实感，图表负责解释，实物负责可信度，数据负责证明。**
