# 青韵智控参赛证据台账

本文件用于统一管理研究报告、商业计划书、PPT、申报书和现场答辩中所有需要“证据支撑”的结论。

原则：**每一个重要结论都对应一个证据；每一个关键数字都能追溯来源；每一个“已完成”都能拿出材料。**

---

# 1. 证据分级

## S 级：正式比赛强证据

- 团队真实样机；
- 原始实验数据；
- 第三方检测 / 检验；
- 茶厂 / 合作社真实应用记录；
- 合同、合作协议、试用证明；
- 正式专利 / 论文 / 软件著作权；
- 可核验营收、订单、报价；
- 政府 / 行业协会权威数据。

## A 级：可作为主要支撑

- 团队调研访谈记录；
- 用户书面反馈；
- 真实 BOM 和采购记录；
- 设备企业官方资料；
- 高质量论文；
- 专利检索结果；
- 公开产品参数与报价。

## B 级：辅助说明

- 主流媒体报道；
- 行业研究报告；
- 电商公开价格；
- 官方活动报道；
- 非核心专家意见。

## C 级：仅供内部参考

- 二手转载；
- 搜索摘要；
- 无原始来源的数据；
- AI 自动生成结论；
- 无法核验的宣传材料。

正式赛稿核心结论尽量由 S/A 级证据支撑。

- [ ] 项目名称完全一致；

- [ ] 参赛组别一致；

- [ ] 专利 / 论文状态一致；
- [ ] 调研人数一致；
- [ ] 合作单位一致；

如果一个数字不能在本证据台账中找到来源，就不应直接进入正式 PPT 或商业计划书。
