# 青韵智控具体 BOM 与器件选型表

本文件用于把 `09_MVP硬件与第一阶段实验方案.md` 进一步落实到可采购、可装配、可测试的器件级方案。

原则：**先完成可重复的数据采集平台，再进入自研 PCB 和闭环控制。** 第一阶段优先选成熟、资料完整、容易替换的器件；正式比赛样机再做集成和外观优化。

> 价格为立项阶段预算区间，仅用于估算，不作为最终采购价。正式采购前应重新询价并保留采购记录。

---

# 1. 第一版系统总体架构

```text
鲜叶 / 做青环境
   ↓
VOC 气味阵列 ─┐
RGB 相机       │
称重模块       ├→ ESP32-S3 / 上位机 → 原始数据记录 → 特征处理
叶温           │
温湿度         │
工艺动作记录 ──┘

气路：采样口 → PTFE 管路 → 采样腔 → MOS 阵列 → 气泵 → 排气
                         ↑
                    洁净空气清洗
```

第一阶段不直接控制摇青设备，仅建立**旁路监测系统**。

# 2. 推荐采购方案

## 2.1 VOC / 电子鼻部分

### 主传感器候选

| 器件 | 数量 | 第一阶段定位 | 选型理由 | 注意事项 | 预算区间 |
|---|---:|---|---|---|---:|
| Figaro TGS2600 | 1 | 广谱空气污染 / 醇类响应通道 | 对氢、乙醇等空气污染物有响应，适合作为综合色变化通道 | 不得解释为某一种 VOC 的定量传感器 | ¥80–150 |
| Figaro TGS2602 | 1 | VOC / 异味主通道 | 对 VOC、氨、硫化物等综合色体较敏感，适合电子鼻主阵列 | 湿度影响必须单独验证 | ¥100–180 |
| Figaro TGS2603 | 1 | 食品气味补充通道 | 对胺类、含硫异味和食品气味具有较高敏感性，可提供与 2600/2602 不同的响应维度 | 仅作为综合色指纹通道 | ¥100–180 |
| BME688 开发板 / 模块 | 1–2 | MEMS 气体响应 + 温湿度补充 | 可采集 gas resistance，并可配置不同 heater profile，适合作为低功耗补充通道 | 第一阶段保留原始 gas resistance，不依赖黑盒分类结果 | ¥70–150/个 |
| 预留模拟气敏通道 | 1–2 | 阵列筛选扩展 | 后续根据第一轮筛选结果加入 | 不建议一开始堆大量 MQ 模块 | — |

第一阶段建议形成 **4–6 个有效气味通道**。不追求数量，而追求：

- 重复性；
- 差异性；
- 湿度鲁棒性；
- 恢复速度；
- 长期稳定性。

### 为什么不直接采购十几个 MQ 传感器

低价 MQ 模块适合功能验证，但存在：

- 模块间一致性差；
- 负载电阻与板卡设计不统一；
- 预热和老化状态不易控制；
- 湿度和温度影响明显；
- 很容易做成“通道很多，但有效信息重复”。

因此如果后续确实需要 MQ 通道，只作为**筛选候选**，不作为正式系统核心卖点。

## 2.2 模拟采集与主控

| 器件 | 数量 | 推荐型号 | 用途 | 预算区间 |
|---|---:|---|---|---:|
| 主控开发板 | 1 | ESP32-S3 DevKit | 采集、串口/USB 通信、未来 Wi-Fi 扩展 | ¥50–100 |
| 外置 ADC | 2 | ADS1115 | 8 路模拟输入，避开 MCU 内置 ADC 一致性问题 | ¥20–40/个 |
| 电阻网络 | 若干 | 0.1% / 1% 精密电阻 | MOS 分压、负载、校准 | ¥20–50 |
| 运放（如后续需要） | 若干 | 低偏置轨到轨运放 | 缓冲 / 滤波 | ¥20–50 |
| 原型 PCB / 洞洞板 | 1–2 | — | 第一阶段快速搭建 | ¥30–80 |

### 主控选择原则

第一阶段优先 ESP32-S3 而不是直接自研 STM32 主板，原因是：

- 开发快；
- USB / 串口方便；
- 后续可增加无线传输；
- 适合先验证整个系统链路。

正式比赛样机可再迁移到团队更熟悉的 STM32 + 自研 PCB。

# 3. 环境与鲜叶状态传感

## 3.1 温湿度

推荐：**SHT31**。

理由：

- I²C 接口；
- 标称湿度精度较高；
- 工业资料完整；
- 可作为 MOS 湿度补偿输入。

建议至少设置两个位置：

1. 环境温湿度；
2. 电子鼻采样腔内温湿度。

预算：约 ¥20–60 / 模块。

---

## 3.2 叶温

推荐：**MLX90614** 非接触红外温度传感器。

用途：

- 记录鲜叶表面温度；
- 与环境温度形成温差特征；
- 辅助判断蒸腾和做青状态变化。

预算：约 ¥50–100。

注意：

- 固定安装高度和视场；
- 不要随意移动测温位置；
- 第一次实验需要与接触式温度计做对照。

---

## 3.3 称重 / 失水

推荐：

- 20 kg 单点 / 梁式称重传感器；
- HX711 24 bit 称重 ADC 模块。

预算：约 ¥40–100。

要求：

- 先做静态标定；
- 记录空载零点；
- 尽量避免摇青时机械振动直接作用于称重平台；
- 正式计算失水率时以每批次 T0 初始质量为基准。

# 4. RGB 视觉

第一阶段推荐直接使用：

**1080p UVC USB 相机 + 固定支架 + 固定补光。**

不建议一开始使用手机随手拍或自动曝光不断变化的摄像头。

要求：

- 分辨率固定；
- 白平衡固定；
- 曝光固定；
- 拍摄距离固定；
- 背景颜色固定；
- 补光色温固定。

预算：

- 相机：¥100–250；
- 补光：¥30–100；
- 支架：¥30–80。

第一阶段视觉目标不是做复杂深度学习，而是稳定获得：

- RGB / HSV / Lab；
- 叶缘红变比例；
- 纹理；
- 卷曲 / 形态变化。

# 5. 气路系统

气路是电子鼻能否重复的关键，不能只把气敏传感器摆在桌上直接闻。

## 5.1 建议器件

| 器件 | 数量 | 建议 | 预算区间 |
|---|---:|---|---:|
| 微型隔膜气泵 | 1 | 12 V，流量约 0.3–1 L/min | ¥30–80 |
| 电磁阀 | 2 | 采样 / 清洗切换 | ¥40–100 合计 |
| 转子流量计 | 1 | 约 0.1–1 L/min | ¥30–80 |
| PTFE 管 | 2–3 m | 4/6 mm 或按接头统一 | ¥30–80 |
| 快插接头 | 若干 | 统一尺寸 | ¥20–60 |
| 采样腔 | 1 | 玻璃 / PTFE / 不锈钢优先 | ¥50–200 |
| 活性炭 / 洁净空气过滤 | 1 套 | 清洗基线 | ¥20–80 |

## 5.2 气路材料原则

优先：

- PTFE；
- 玻璃；
- 不锈钢。

尽量避免长期使用：

- PVC 软管；
- 气味明显的硅胶管；
- 未处理的 PLA 打印气路。

原因是材料本身可能吸附或释放挥发物，影响重复性。

## 5.3 第一阶段起始参数

建议初始设定：

- 采样流量：0.3–0.5 L/min；
- 采样时间：60–180 s；
- 清洗时间：直到主要通道恢复至基线窗口；
- 采样腔体积：约 100–300 mL。

以上仅作为第一轮实验起点，必须通过 E2 / E3 实验重新确定。

# 10. 不建议现在购买的东西

当前不建议：

- 昂贵 NIR / 高光谱设备；
- 工业 GC 类在线分析仪；
- 大量品牌不同、质量不明的 MQ 模块；
- 高价工控机；
- 尚无数据支撑的复杂执行设备；
- 为了展示而购买的大尺寸触摸屏。

原因：这些设备不会解决当前最关键的问题——**数据是否稳定、状态是否可解释、方法是否能跨批次成立。**

---

# 11. 器件进入正式样机前的淘汰标准

任何传感器满足以下情况之一，应考虑淘汰：

1. 同条件重复实验波动过大；
2. 与其他通道高度重复且没有增量信息；
3. 湿度影响远大于茶叶状态变化；
4. 恢复时间过长，无法满足连续采样；
5. 老化漂移难以校正；
6. 跨批次没有稳定可解释关系。

正式阵列应通过实验筛选，而不是一开始就人为固定。

# 13. 当前推荐结论

第一版优先实现：

> **TGS2600 + TGS2602 + TGS2603 + BME688 → ADS1115 / I²C → ESP32-S3 → Windows 上位机**

并同步接入：

> **SHT31 ×2 + MLX90614 + HX711 + UVC 相机。**

这套配置的目标不是一步做到最终产品，而是以较低成本快速回答三个最重要的问题：

1. 做青过程中是否存在稳定、可重复的多模态变化轨迹；
2. 哪些通道真正具有增量价值；
3. 这些状态变化能否和师傅判断及最终品质建立关系。
