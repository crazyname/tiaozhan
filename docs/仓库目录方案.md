# 仓库目录方案

建议仓库新增如下结构：

```text

tiaozhan/

├─ assets/

│  ├─ photos/

│  └─ figures/

├─ docs/

│  ├─ README.md

│  ├─ sources.md

│  ├─ PPT_配图清单.md

│  └─ 仓库目录方案.md

└─ ppt/

   └─ （后续放PPT源文件/导出PDF）

```

## 说明

- `assets/photos/`：网页搜索得到的场景照片与参考图。

- `assets/figures/`：自绘图，优先用于正式PPT。

- `docs/`：来源、使用说明、页码配图清单。

- `ppt/`：后续放 `.pptx`、导出的 `.pdf`、演讲稿。
