# tiaozhan_assets

本目录为《青韵智控——凤凰单丛做青多模态感知与自适应闭环控制系统》准备的PPT素材包。

## 目录结构
- photos/：网页搜索得到的参考照片与参考图
- figures/：根据项目内容自绘的可直接上PPT的示意图

## 建议使用方式
1. 封面/落地页优先用 photos/ 中的茶园、鲜叶照片。
2. 技术页优先用 figures/ 中的流程图、闭环图、实验设计图。
3. 公开提交到 GitHub 仓库前，建议：
   - 优先使用自绘图（版权风险最低）
   - 对网页搜索得到的照片，重新回到原始来源页面确认授权、署名与可复用范围
