## 如何正确引用证据

`data/hardware_tests/数据结果.xlsx` 为已有处理结果文件，缺乏公开的完整逐秒原始证据。说明文档记录了处理结果表中数字的复算关系、例外与“是否可写”限制；现阶段不应把这一复算写成原始数据的外部真实性认证。

硬件测试表与当前仓库固件版本存在不同层级和不同时间的验证材料。避免把某次采样表结果简单归因于本仓库当前固件已实现的全部气路、电机或测量精度。

此外，代码中的预研、未来架构、计划指标应明确使用“设计中/待验证”，而非“已实现/已提高”。

## 进入更高成熟度所需证据

1. 真实器件型号、接线、供电与独立安全链的照片和验收记录。
2. 气敏、温湿度、称重、叶温的原始时间序列、参考仪表、标定与条件。
3. 电机反馈 RPM、停止响应、故障注入、断线后状态和持久化日志。
4. 多批次做青人工状态标签及跨批次验证，不用模拟数据替代。
5. 状态—决策—执行—反馈端到端记录及三组对照的真实品质数据。
