# 滚筒人工控制基准 DRUM-v0.1

日期：2026-09-22。此为选型和软件开发基准，未采购/接线/上板验收，不是已验证设备。范围为小型实验平台，先空载，再经电流/温升/转速验收后加小量鲜叶；不宣称适用于生产滚筒或任何确定的处理量。状态模型不参与启动。

## 1. 固定选型

| 项目 | 固定型号 / 设计选择 | 依据与边界 |
|---|---|---|
| 主控 | ESP32-S3-DevKitC-1 N8R8 | 沿用已有主控；仅motor构建启用新GPIO |
| 电机及反馈 | Pololu **4695**，24V 100:1 37D减速电机，双通道霍尔编码器 | 实际减速比102.0833:1，电机轴64计数/转（四边沿），减速输出约6533.333计数/转；空载约100RPM。不能把堵转力矩当连续额定力矩。[官方参数](https://www.pololu.com/product/4695) |
| 驱动器 | Pololu **2992 G2 24v13** | PWM/DIR，3.3V控制兼容，SLP低关闭，FLT开漏低故障；故障本身会自动恢复，软件必须锁存故障。[官方说明](https://www.pololu.com/product/2992) |
| 编码器电平转换 | TI **SN74LVC2G17DBVR** | 3.3V供电、5V容限输入，双施密特缓冲；每片电源旁100nF。编码器供5V，A/B不能直连ESP32。[TI资料](https://www.ti.com/product/SN74LVC2G17) |
| 急停安全继电器 | Pilz **PNOZ X2.8P 24VACDC 3n/o 1n/c，777301** | 独立硬件安全链、人工复位；按厂家对应手册设计双通道急停/防护输入与输出回路，不由PC软件代替。[官方型号](https://www.pilz.com/en-INT/eshop/product/777301) |
| 传动 | 电机减速输出与滚筒 **1:1联轴器** | 滚筒由独立轴承支承，不让电机轴承担滚筒径向载荷；改变传动比必须同步改测速换算和版本 |
| 电源 | 24V直流可限流实验电源，逻辑支路独立5V/3.3V | 首次空载限流不高于0.75A，出现限流/启动失败即停止分析，不能盲目加大电流 |

电机厂家建议连续负载不超过10kg·cm，并给出一般连续电流建议不超过堵转电流的25%；本电机堵转电流约3A，因此0.75A作为初始台架限流选择。滚筒质量、偏心、轴承摩擦、实际电流与温升均须实测；输出轴是否具备足够力矩由实验确定。

24v13的默认限流远高于此小电机所需，不能用其默认保护替代电机限流。CS输出与PWM驱动相位有关，本版不把它直接换算成电流，`motor_current_a=null`。使用实验电源/外部仪表记录电流，后续若接采集需单独标定。

## 2. 固定GPIO与低压接线

| 信号 | GPIO | 接法 |
|---|---:|---|
| MOTOR_ENABLE_N | 7 | 安全链允许的无源辅助触点闭合接GND；外部10k上拉3.3V，断线禁止 |
| MOTOR_PWM | 10 | 驱动PWM，20kHz/10bit；外部10k下拉 |
| MOTOR_DIR | 11 | 驱动DIR；外部10k下拉；1正转、-1反转，按编码器符号实测核对 |
| MOTOR_SLEEP | 12 | 驱动SLP，HIGH允许；外部1k下拉，确保MCU复位/未供电时实际SLP为LOW（须实测） |
| ENCODER_A | 13 | 编码器A → LVC2G17输入1 → 输出1 → GPIO13 |
| ENCODER_B | 14 | 编码器B → LVC2G17输入2 → 输出2 → GPIO14 |
| MOTOR_FAULT_N | 15 | 驱动FLT，外部10k上拉3.3V；LOW故障 |
| MOTOR_GUARD_N | 21 | 防护罩独立辅助触点闭合接GND；外部10k上拉3.3V，断线禁止 |

编码器：蓝线5V、绿线GND、黄/白为A/B；红/黑是电机两端，接OUTA/OUTB，不接GPIO。首次用手转动减速轴核对计数与方向，确认低速正转反馈为正；若符号相反，仅在断电状态按记录修正电机极性或A/B接线。禁止通过绝对值隐藏反向反馈。

仅使用GPIO号，排针位置核对[Espressif板卡图](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html)。不使用USB、PSRAM或启动配置脚；原有传感与气路引脚保持不变。

电源与安全链：24V电源 → 与实际负载/线径匹配的保险和独立硬件安全输出回路 → 驱动VIN；逻辑供电可保持以记录故障。按PNOZ厂家手册完成手动复位、双通道急停、输出反馈及防护回路，若需外部接触器按实际DC负载类别和浪涌选择并核对，不用GPIO驱动安全继电器。固件只读取其独立无源辅助触点，不将24V接入GPIO。

驱动器附近配置足够的储能电容，线径、保险、续流/浪涌吸收和再生能量处理须由电气装配人员按实际负载验证，保证VIN瞬态低于40V绝对上限；本文件不提供未经负载验证的保护器件定值。所有电机/传动部件封闭防护，停电且确认停稳后才能开罩，断电会有惯性滑行，不承诺瞬时机械停止。

## 3. 固件、命令与遥测

构建 `pio run -d hardware/esp32_s3_mvp -e esp32s3_motor`。默认 `esp32s3` 和 `esp32s3_air` 不启用滚筒、不操作预留电机GPIO。motor版同时具备有限时气路功能。

固件 `QY-FW-0.3.0` / `JSONL-v0.3` 新命令：

```json
{"cmd":"motor","rpm":10,"direction":1,"duration_ms":10000,"session_id":"0123456789abcdef0123456789abcdef","request_id":1}
{"cmd":"motor_heartbeat","session_id":"0123456789abcdef0123456789abcdef"}
{"cmd":"motor_stop","request_id":2}
{"cmd":"motor_reset","request_id":3}
```

上位机生成随机session_id；heartbeat只是续租，不能启动。motor相关响应回显cmd/request_id，accepted仅表示控制器接受命令，实际运动查看编码器反馈。session_id用于隔离旧会话，不是网络身份认证；串口按可信物理连接使用。

- 人工目标5～30RPM，单次1～300秒；禁止运行中重新启动/换向。停止且反馈低于1RPM保持至少1秒后才允许下一次启动或故障复位。
- 100ms编码器计数窗，10ms独立控制任务；PI初值Kp=0.012、Ki=0.004、前馈target/100，占空比上限0.60，上升斜率0.5/s。仅为台架调参起点，尚无稳定性/精度实测。
- 1.2秒无匹配主机心跳、1.5秒无主循环心跳、互锁断开、FLT、超过45RPM、方向相反超过2RPM、启动后连续1秒不足1RPM或无效反馈均关闭PWM/SLP并锁存故障。此无运动检查不能区分堵转与编码器掉线。
- 上位机每250ms续租，GUI健康回调超过750ms未更新则停止续租；串口断线、退出、命令结果未知不续租、不重放动作。气路自身仍采用原有限时策略，不随此心跳改变。
- 停止按钮关闭输出的请求在控制任务下一次执行时生效；独立急停直接切断执行供电。安全链解除或软件故障复位均不会自动启动。

新增字段：`motor_compiled/interlock/running/fault`、`shake_target_rpm`、带方向的`shake_actual_rpm`、`shake_direction`、`shake_start_time/end_time`、`shake_duration_s`、`motor_pwm_duty`、`motor_current_a`。起止时间为64位MCU启动后毫秒，`shake_time_kind=mcu_uptime_ms`；表示控制器运行区间，不是物理零速时刻。固件禁用/反馈未就绪时实际RPM为null。电流无测量保持null。主机保留全部字段并产生MOTOR_START/END及状态日志。

## 4. 上板验收顺序（全部待测）

1. 断开电机功率，量测GPIO/SLP上电及复位默认关闭，核对5V编码器转换后不超3.3V。
2. 独立测试急停/罩门/手动复位回路；PC断电和MCU复位均不绕过硬件断电。确认惯性停机后的开罩流程。
3. 手转输出轴，对照独立转速计验证计数倍率、方向、零速；拔编码器不生成伪造转速。
4. 无机械负载、限流电源，5RPM/1秒起步；验证正反转、停止、重新启动必须停稳。记录电流、PWM、RPM和温升后再调PI。
5. 拔USB、停止GUI心跳、阻塞主循环、断使能、开罩、FLT注入、编码器失联，测量实际输出关闭延迟及禁止自动恢复。
6. 每一目标转速和负载测稳态误差、超调、启动电流和连续温升；无验收记录不进入鲜叶实验。
7. 完成4～8小时联机及异常恢复，保留原始批次、版本、接线实拍和验收表。当前代码/仿真/编译通过不能填写实物PASS。
