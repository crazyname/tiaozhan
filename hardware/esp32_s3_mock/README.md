# ESP32-S3 Mock Firmware

用于在真实传感器到货、接线和标定完成前，先把**通信协议、上位机、数据落盘、事件标记**联调跑通。

## 功能

- ESP32-S3 通过 USB Serial 发送 JSON Lines；
- 默认波特率 `115200`；
- 每秒发送 1 帧 `sensor` 数据；
- 字段与 `docs/12_第一阶段上位机与数据格式设计.md` 保持一致；
- 模拟 4 路气敏、BME688、采样腔温湿度、环境温湿度、叶温、质量、泵阀状态。

## 使用

1. Arduino IDE / PlatformIO 选择 ESP32-S3 开发板；
2. 编译并烧录 `esp32_s3_mock.ino`；
3. 打开串口监视器确认每秒出现一行 JSON；
4. 关闭串口监视器，再由 `software/host_mvp/app.py` 连接该串口。

## 验收

连续运行 30 分钟时应满足：

- `seq` 单调递增；
- `t_ms` 单调递增；
- 每行均为合法 JSON；
- 上位机无持续解析错误；
- CSV 能持续落盘。

## 注意

本固件仅用于**软件与协议联调**，模拟曲线不得用于任何实验结果、算法准确率或比赛材料。真实实验必须替换为传感器实测数据。
