# 二、四份材料统一口径

项目名称：**青韵智控——凤凰单丛做青多模态感知与自适应控制系统**

当前参赛组别按：**农业绿色发展** 准备；若学校最终通知不同，以正式表格为准。

项目核心闭环：

> **多模态感知 → 做青状态估计 → 工艺决策 → 执行 → 品质反馈**

统一项目定位：

> 凤凰单丛做青已经可以机械化执行，但“什么时候摇、摇多久、摇多重、静置多久”仍高度依赖制茶经验。青韵智控尝试把香气、视觉、失水、叶温等综合判断转化为可连续测量的状态，并让实时鲜叶状态参与工艺决策。

统一技术边界：

- “自动摇青机”不能单独作为创新；
- “电子鼻识别做青阶段”不能单独作为创新；
- “用了 AI”不能作为创新；
- 核心技术增量应由多模态增益、跨批次稳定和状态驱动控制的真实实验来证明。

# 四、PPT 视觉规范

视觉定位：**科研竞赛答辩 × 茶产业视觉识别**。

核心原则：

- 竞赛答辩风为主，茶文化只负责项目识别；
- 白色 / 极浅灰绿为主背景；
- 使用单一茶绿色体系；
- 茶山、茶园和竹筛只做低对比度背景或局部实拍；
- 正文页顶部只保留轻量导航，与正文自然连接；
- 目录页不重复顶部导航；
- 主要使用编号、细线、分栏、流程图、数据图和实拍图片；
- 避免手帐风、海报风、大面积卡片、层层套框、强渐变和复杂 3D。

推荐色值：

- 深茶绿 `#145A32`
- 中茶绿 `#2E8B57`
- 浅茶绿 `#DDEFE4`
- 极浅背景 `#F7FBF8`
- 正文深灰 `#2F3A35`
