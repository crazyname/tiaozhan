# 青韵智控

**凤凰单丛做青多模态感知与自适应控制系统**

本仓库用于“挑战杯”项目的研究、文献、作品研发、商业计划、答辩结构、视觉设计、实验实施与比赛策略管理。

当前版本已按照第十五届“挑战杯”中国大学生创业计划竞赛官方**汇报模板**与**商业计划书模板**重新校准，并开始进入 MVP 硬件、上位机与真实数据采集阶段。

项目始终坚持：

> **不把计划写成成果，不把预测写成事实，不把已有技术包装成首创。**

## 官方 PPT 模板约束

正式汇报按 8 个部分组织：

1. 项目背景
2. 项目概述
3. 项目优势
4. 项目应用
5. 社会价值
6. 商业模式
7. 团队介绍
8. 未来展望

必须遵守：

- 正文不含封面、封底，控制在 20 页以内；
- 页面比例 16:9；
- 国赛初审 PDF 控制在 30 MB 以内；
- 国赛终审 PPT 控制在 150 MB 以内；
- 设计遵循简洁、实用、清晰原则；
- 不追求过度视觉化、艺术化；
- 不随意使用复杂动效、3D 渲染、特效字体；
- 标题规范准确；
- 正式提交时删除模板说明文字。

仓库采用浅绿色 / 茶绿色视觉体系，但**官方结构和证据表达优先于视觉风格**。

## 当前研发主线

```text
真实需求调研
    ↓
文献 / 专利查新
    ↓
MVP BOM 与采购
    ↓
电子鼻气路 + 多模态采集
    ↓
上位机 + 统一数据格式
    ↓
传感器稳定性实验
    ↓
第一批真实做青：只做被动监测
    ↓
多批次数据积累
    ↓
多模态状态估计
    ↓
人工确认的半自动控制
    ↓
A/B/C 对照实验
    ↓
状态驱动闭环控制
    ↓
真实茶厂 / 合作社试验
    ↓
市场、成本与付费验证
    ↓
商业计划书 / PPT / 答辩
```

PPT 和商业计划书不是独立“包装材料”，而是研发证据的不同表达方式。

## 当前最高优先级任务

### P0：完成第一批采购

依据 [`docs/11_具体BOM与器件选型表.md`](docs/11_具体BOM与器件选型表.md)，优先采购：

- ESP32-S3；
- ADS1115 ×2；
- TGS2600 / TGS2602 / TGS2603；
- BME688；
- SHT31 ×2；
- 气泵、电磁阀、流量计、PTFE 管；
- 电源和基础连接件。

目标是先完成**电子鼻闭环气路 + 稳定数据采集**。

### P0：完成上位机最小版本

依据 [`docs/12_第一阶段上位机与数据格式设计.md`](docs/12_第一阶段上位机与数据格式设计.md)：

- 串口数据接收；
- JSON Lines 协议；
- CSV 落盘；
- 双时间戳；
- seq 缺包检测；
- 实时曲线；
- 实验事件按钮；
- 图像索引；
- session_check。

### P0：完成第一阶段基础实验

优先顺序：

1. 电子系统连续运行；
2. MOS 重复性；
3. 温湿度干扰；
4. 清洗恢复；
5. 称重标定；
6. 相机固定条件验证；
7. 多模态同步采集。

### P0：继续真实需求访谈

同步执行 [`docs/07_市场调研与商业验证计划.md`](docs/07_市场调研与商业验证计划.md)，不要等样机完成后才去找茶企和制茶师傅。

## 第一批真实做青的进入条件

在进入真实茶叶实验前，应至少满足：

- 上位机连续运行 ≥8 h；
- MOS 基线和重复性已有记录；
- 采样 / 清洗气路能够稳定切换；
- 温湿度和称重均完成基本标定；
- 相机曝光 / 白平衡 / 机位固定；
- 批次目录和 meta.yaml 能自动建立；
- SHAKE_START / SHAKE_END / MASTER_CHECK 等事件可一键记录；
- 数据异常可以通过 quality_flag 标记；
- 原始数据、图片、事件和实验版本可互相追溯。

第一批真实做青仍然坚持：

> **只监测，不自动控制。**

## 项目视觉方向

后续正式 PPT 统一采用：

- 浅绿色为主色，深绿色为强调色；
- 茶叶与真实生产场景作为视觉主体；
- 实拍照片、论文证据、系统结构图、真实数据图分工明确；
- 技术页强调证据链和信息层级；
- 不使用旧版低分辨率整页 PNG；
- 不为了“高级感”牺牲可读性；
- 正式比赛阶段逐步减少素材图，增加真实项目图。

原则：

> **照片负责真实感，图表负责解释，实物负责可信度，数据负责证明。**

研究报告、商业计划书、PPT、申报书、答辩回答中的以下信息必须保持一致：

- 项目名称；
- 队伍名称；
- 参赛组别；
- 核心技术；
- 创新点；
- 样机状态；
- 实验结果；
- 专利 / 论文；
- 应用单位；
- 市场数据；
- 成本与售价；
- 营收 / 融资；
- 团队成员与分工。

任何一个数字发生变化，都应同步检查其他材料，并在 [`docs/08_参赛证据台账.md`](docs/08_参赛证据台账.md) 中找到来源。

## 当前原则

1. “电子鼻识别做青阶段”不能单独作为创新；
2. “自动摇青机”不能单独作为创新；
3. 多模态必须通过消融或对比实验证明增量价值；
4. 自适应控制必须用固定程序作为基线；
5. 最终评价必须回到成茶品质和批次稳定性；
6. 商业模式必须经过真实客户、成本与付费意愿验证；
7. 正式赛稿优先展示实物、实验、数据、应用，而不是口号和装饰图；
8. 所有重要结论和关键数字都应进入证据台账；
9. 原始数据必须保留且可追溯；
10. 第一批真实做青不允许在尚未验证感知可靠性的情况下直接闭环控制。
