## 官方 PPT 模板约束

正式汇报按 8 个部分组织：

1. 项目背景
2. 项目概述
3. 项目优势
4. 项目应用
5. 社会价值
6. 商业模式
7. 团队介绍
8. 未来展望

必须遵守：

- 正文不含封面、封底，控制在 20 页以内；
- 页面比例 16:9；
- 国赛初审 PDF 控制在 30 MB 以内；
- 国赛终审 PPT 控制在 150 MB 以内；
- 设计遵循简洁、实用、清晰原则；
- 不追求过度视觉化、艺术化；
- 不随意使用复杂动效、3D 渲染、特效字体；
- 标题规范准确；
- 正式提交时删除模板说明文字。

仓库采用浅绿色 / 茶绿色视觉体系，但**官方结构和证据表达优先于视觉风格**。

## 官方商业计划书约束

正式商业计划书包含：

1. 执行摘要
2. 项目概述
3. 项目优势
4. 市场分析
5. 商业模式
6. 团队介绍
7. 财务分析
8. 融资需求
9. 风险控制
10. 未来展望

主要约束：

- 执行摘要 800 字以内；
- 正文控制在 12000 字以内；
- 文件控制在 10 MB 以内；
- 市场、技术、财务、应用等关键数据必须有来源或真实记录；
- 论文、专利、合同、媒体报道等支撑材料按申报要求另行上传；
- 项目优势、市场分析、商业模式、财务分析属于重点章节；
- 无公司、营收、融资、订单或落地成果时必须如实说明，禁止虚构。

详细排版要求见 [`docs/06_商业计划书结构模板.md`](docs/06_商业计划书结构模板.md)。

## 当前研发与比赛工作流

```text
真实需求调研
    ↓
文献 / 专利查新
    ↓
MVP 硬件与采集系统
    ↓
多批次做青数据
    ↓
状态估计与控制策略
    ↓
A/B/C 对照实验
    ↓
真实茶厂 / 合作社试验
    ↓
市场与成本验证
    ↓
商业计划书
    ↓
PPT / 答辩 / 展示
    ↓
评委问题反推实验与证据补强
```

PPT 和商业计划书不是独立“包装材料”，而是研发证据的不同表达方式。

## 当前最需要补的四类证据

### 1. 真实样机

至少形成：

- 多路 MOS 气敏采集；
- 温湿度 / 叶温；
- RGB；
- 称重；
- 采样 / 清洗气路；
- 数据采集与上位机；
- 小型做青执行平台或可改造接口。

### 2. 真实实验

至少完成：

- 传感器重复性；
- 温湿度影响；
- 漂移 / 基线；
- 多批次数据；
- A/B/C 做青对照；
- 按整批次划分训练 / 验证，避免数据泄漏。

### 3. 真实应用

优先获得：

- 茶厂 / 合作社调研；
- 师傅访谈；
- 试用记录；
- 小试 / 中试；
- 应用证明 / 合作意向；
- 真实反馈。

### 4. 真实成本与商业验证

逐步建立：

- BOM；
- 样机成本；
- 安装 / 维护成本；
- 客户可接受价格；
- 目标客户数量；
- 付费意愿；
- 销售 / 改造 / 服务模式验证。

## 项目视觉方向

后续正式 PPT 统一采用：

- 浅绿色为主色，深绿色为强调色；
- 茶叶与真实生产场景作为视觉主体；
- 实拍照片、论文证据、系统结构图、真实数据图分工明确；
- 技术页强调证据链和信息层级；
- 不使用旧版低分辨率整页 PNG；
- 不为了“高级感”牺牲可读性；
- 正式比赛阶段逐步减少素材图，增加真实项目图。

原则：

> **照片负责真实感，图表负责解释，实物负责可信度，数据负责证明。**

## 材料一致性原则

研究报告、商业计划书、PPT、申报书、答辩回答中的以下信息必须保持一致：

- 项目名称；
- 核心技术；
- 创新点；
- 样机状态；
- 实验结果；
- 专利 / 论文；
- 应用单位；
- 市场数据；
- 成本与售价；
- 营收 / 融资；
- 团队成员与分工。

任何一个数字发生变化，都应同步检查其他材料。

## 当前原则

1. “电子鼻识别做青阶段”不能单独作为创新；
2. “自动摇青机”不能单独作为创新；
3. 多模态必须证明比单模态更有价值；
4. 自适应控制必须用固定程序作为基线；
5. 最终评价必须回到成茶品质和批次稳定性；
6. 商业模式必须经过真实客户、成本与付费意愿验证；
7. 正式赛稿优先展示实物、实验、数据、应用，而不是口号和装饰图。
