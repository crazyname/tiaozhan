`研究报告 → 文献核验/查新 → 比赛评审逻辑校准 → PPT叙事 → 配图/数据可视化 → PPT终稿 → 模拟答辩 → 评委问题反推实验与证据补强`

## 项目视觉方向

后续 PPT 统一采用：

- **浅绿色为主色，深绿色为强调色**；
- 农业与茶叶质感为视觉主体，避免普通“科技蓝”模板感；
- 实拍照片、论文数据图、结构示意图分工明确；
- 技术页强调证据链和信息层级，不使用旧版低分辨率整页 PNG 直接铺版。

## 比赛打磨原则

- 不把已有“电子鼻识别做青阶段”“自动摇青机”等技术包装成首创；
- 每个创新点都必须对应已有技术缺口、具体方法和可验证指标；
- 正式参赛阶段优先展示实物、真实实验、真实数据和应用反馈；
- 每轮模拟答辩的质疑应转化为新的实验、实物或支撑证据，而不只是优化回答话术。
