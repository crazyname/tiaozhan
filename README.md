项目当前处于 MVP 硬件、上位机与真实数据采集准备阶段。

> **不把计划写成成果，不把预测写成事实，不把已有技术包装成首创。**

## PPT 当前定版

### 页数

- 总页数：**16 页**
- 封面：1 页
- 正文：14 页
- 封底：1 页
- **不设置团队介绍正文页**

当前正文保留 7 个板块：

1. 项目背景
2. 项目概述
3. 项目优势
4. 项目应用
5. 社会价值
6. 商业模式

## PPT 视觉风格已锁定

正文统一采用：

- 白色 / 极浅灰绿底；
- **单一茶绿色体系**，不再蓝绿混色；
- 左上章节编号 + 页面标题；
- 右上简洁章节导航；
- 2–4 个卡片 / 图表模块；
- 浅绿边框、浅底、轻圆角；
- 不使用贯穿整页的大项目标题；
- 不使用左右明显不同的深浅色主题；
- 不使用复杂 3D、霓虹、强渐变或高饱和科技蓝。

推荐色值：

- 深茶绿 `#145A32`
- 中茶绿 `#2E8B57`
- 浅茶绿 `#DDEFE4`
- 极浅背景 `#F7FBF8`
- 正文深灰 `#2F3A35`

原则：

> **同一页左右像同一套设计，同一套 PPT 每一页像同一个项目。**

## 官方材料约束

根据当前官方汇报模板：

- 正文不含封面、封底，控制在 20 页以内；
- 页面比例 16:9；
- 初审 PDF 控制在 30 MB 以内；
- 终审 PPT 控制在 150 MB 以内；
- 设计应简洁、实用、清晰；
- 不追求过度视觉化、复杂动效、3D 渲染和特效字体；
- 无对应内容时可合理删减模板板块，但整体逻辑必须完整。

商业计划书仍按官方十章结构执行，详见 `docs/06_商业计划书结构模板.md`。

## 当前原则

1. “电子鼻识别做青阶段”不能单独作为创新；
2. “自动摇青机”不能单独作为创新；
3. 多模态必须通过消融或对比实验证明增量价值；
4. 自适应控制必须用固定程序作为基线；
5. 最终评价必须回到成茶品质和批次稳定性；
6. 市场、成本、售价和付费意愿必须由真实调研支持；
7. PPT 优先展示实物、实验、数据和应用，不用装饰图代替证据；
8. 原始数据必须保留且可追溯；
9. 第一批真实做青只监测，不直接闭环控制。
