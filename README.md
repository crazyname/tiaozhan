`真实需求调研 → 文献/专利查新 → 采集系统 MVP → 第一批做青数据 → 状态估计 → 样机 → 三组对照实验 → 应用验证 → PPT终稿 → 模拟答辩 → 评委问题反推实验与证据补强`

2. 确认真实茶季采样与实验机会；
3. 搭建电子鼻 + 温湿度 + 称重的第一版同步采集系统；
4. 制定批次编号、采样节点和实验 SOP；
5. 建立“评委问题—证据缺口—研发动作”台账。

## 项目视觉方向

后续 PPT 统一采用：

- **浅绿色为主色，深绿色为强调色**；
- 农业与茶叶质感为视觉主体，避免普通“科技蓝”模板感；
- 正式比赛优先展示真实实物、实验现场、数据图和用户场景；
- 技术页强调证据链和信息层级，不使用旧版低分辨率整页 PNG 直接铺版。

## 比赛打磨原则

- 不把已有“电子鼻识别做青阶段”“自动摇青机”等技术包装成首创；
- 每个创新点都必须对应已有技术缺口、具体方法和可验证指标；
- 没有真实实验数据前，不写“提升 XX%”或“行业领先”等结果型结论；
- 正式参赛阶段优先展示实物、真实实验、真实数据和应用反馈；
- 每轮模拟答辩的质疑都应转化为新的实验、实物或支撑证据，而不只是优化回答话术。
