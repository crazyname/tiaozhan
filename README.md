# 青韵智控

**凤凰单丛做青多模态感知与自适应控制系统**

本仓库用于“挑战杯”项目的研究、文献、作品研发、商业计划、答辩结构、视觉设计与比赛策略管理。

当前版本已按照第十五届“挑战杯”中国大学生创业计划竞赛官方**汇报模板**与**商业计划书模板**重新校准。项目仍处于研发与验证阶段，因此仓库坚持：

> **不把计划写成成果，不把预测写成事实，不把已有技术包装成首创。**

## 官方 PPT 模板约束

正式汇报按 8 个部分组织：

1. 项目背景
2. 项目概述
3. 项目优势
4. 项目应用
5. 社会价值
6. 商业模式
7. 团队介绍
8. 未来展望

必须遵守：

- 正文不含封面、封底，控制在 20 页以内；
- 页面比例 16:9；
- 国赛初审 PDF 控制在 30 MB 以内；
- 国赛终审 PPT 控制在 150 MB 以内；
- 设计遵循简洁、实用、清晰原则；
- 不追求过度视觉化、艺术化；
- 不随意使用复杂动效、3D 渲染、特效字体；
- 标题规范准确；
- 正式提交时删除模板说明文字。

仓库采用浅绿色 / 茶绿色视觉体系，但**官方结构和证据表达优先于视觉风格**。

## 当前研发与比赛工作流

```text
真实需求调研
    ↓
文献 / 专利查新
    ↓
MVP 硬件与采集系统
    ↓
传感器标定与系统稳定性实验
    ↓
第一批真实做青被动监测
    ↓
多批次做青数据
    ↓
状态估计与多模态消融实验
    ↓
半自动建议 / 人工确认
    ↓
A/B/C 对照实验
    ↓
状态驱动闭环控制
    ↓
真实茶厂 / 合作社试验
    ↓
市场与成本验证
    ↓
商业计划书
    ↓
PPT / 答辩 / 展示
    ↓
评委问题反推实验与证据补强
```

PPT 和商业计划书不是独立“包装材料”，而是研发证据的不同表达方式。

## 当前最高优先级任务

### P0：真实需求调研

执行 [`docs/07_市场调研与商业验证计划.md`](docs/07_市场调研与商业验证计划.md)：

- 制茶师傅问题访谈；
- 茶企 / 合作社负责人访谈；
- 设备企业 / 自动化从业者访谈；
- 茶学 / 食品加工人员访谈；
- 收集真实原话、现场照片、现有设备和当前控制方式。

### P0：搭第一版感知 MVP

按 [`docs/09_MVP硬件与第一阶段实验方案.md`](docs/09_MVP硬件与第一阶段实验方案.md) 推进：

- 4–6 路 MOS 阵列；
- 外置 ADC + MCU；
- 采样 / 清洗气路；
- 环境温湿度；
- 叶温；
- RGB；
- 称重；
- 上位机数据记录；
- 真实 BOM 与采购记录。

### P0：先完成 E0–E5，不直接闭环控制

优先顺序：

1. 电气 / 数据链路稳定性；
2. MOS 重复性；
3. 湿度干扰；
4. 清洗恢复；
5. 称重标定；
6. 多模态时间同步。

只有这些基础通过后，才进行真实茶叶批次采样。

### P0：第一次真实做青只做被动监测

严格执行 [`docs/10_第一批做青采样SOP.md`](docs/10_第一批做青采样SOP.md)。

第一批重点是：

- 完整时间轴；
- 全部摇青 / 静置事件；
- 师傅原始判断；
- MOS / RGB / 失水 / 叶温 / 环境同步；
- 真实故障记录；
- 不自动控制，不为了“效果”修改标签或数据。

### P1：开始积累正式赛稿可用素材

每一次调研和实验都同步保存：

- 原始数据；
- 实验照片；
- 样机照片；
- 视频；
- 用户原话；
- 采购记录；
- 版本号；
- 失败记录；
- 修改原因。

并同步更新 [`docs/08_参赛证据台账.md`](docs/08_参赛证据台账.md)。

## 第一阶段里程碑

### M1｜MVP 可连续采集

- 系统连续运行 ≥4 h；
- 关键数据不丢失；
- 时间戳统一；
- 泵阀动作不导致系统异常。

### M2｜传感器特性被量化

- MOS 重复性；
- 湿度影响；
- 清洗恢复；
- 称重标定；
- 基线漂移记录。

### M3｜完成第一批真实做青数据链

至少获得：

- 一套完整原始传感数据；
- 一套工艺事件；
- 一套师傅判断标签；
- 一组鲜叶关键帧；
- 一套实验现场照片；
- 一份失败与异常记录。

### M4｜多批次后才进入模型结论

第一批数据只用于验证采集链和初步规律。

不得用单一批次直接宣称：

- 跨批次泛化；
- 自适应控制有效；
- 多模态显著优于单模态；
- 成茶品质得到稳定提升。

这些结论必须由后续独立批次、消融实验和 A/B/C 对照支撑。

## 当前最需要补的四类证据

### 1. 真实样机

至少形成：

- 多路 MOS 气敏采集；
- 温湿度 / 叶温；
- RGB；
- 称重；
- 采样 / 清洗气路；
- 数据采集与上位机；
- 小型做青执行平台或可改造接口。

### 2. 真实实验

至少完成：

- 传感器重复性；
- 温湿度影响；
- 漂移 / 基线；
- 多批次数据；
- A/B/C 做青对照；
- 按整批次划分训练 / 验证，避免数据泄漏。

### 3. 真实应用

优先获得：

- 茶厂 / 合作社调研；
- 师傅访谈；
- 试用记录；
- 小试 / 中试；
- 应用证明 / 合作意向；
- 真实反馈。

### 4. 真实成本与商业验证

逐步建立：

- BOM；
- 样机成本；
- 安装 / 维护成本；
- 客户可接受价格；
- 目标客户数量；
- 付费意愿；
- 销售 / 改造 / 服务模式验证。

## 当前原则

1. “电子鼻识别做青阶段”不能单独作为创新；
2. “自动摇青机”不能单独作为创新；
3. 多模态必须证明比单模态更有价值；
4. 自适应控制必须用固定程序作为基线；
5. 最终评价必须回到成茶品质和批次稳定性；
6. 商业模式必须经过真实客户、成本与付费意愿验证；
7. 正式赛稿优先展示实物、实验、数据、应用，而不是口号和装饰图；
8. 所有重要结论和关键数字都应进入证据台账；
9. 第一批真实数据优先保证完整和可追溯，不追求“漂亮结果”；
10. 原始数据不覆盖、不手工改写，所有清洗和特征工程必须另存。
