# 青韵智控采集工作台 v0.8

用于做青实验的串口采集、人工事件、自动拍照和师傅标签记录，支持人工去皮、砝码标定、限时采样/吹扫及停止命令。

## 启动

Windows环境，首次安装：

```powershell
cd D:\tiaozhan\software\host_mvp
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

无需硬件体验（传感器和图像都是模拟数据）：

```powershell
.\.venv\Scripts\python.exe app.py --simulate
```

连接真实设备：

```powershell
.\.venv\Scripts\python.exe app.py --port COM7
```

硬件采用[ESP32-S3-DevKitC-1 N8R8配套固件](../../hardware/esp32_s3_mvp/README.md)，接线按[引脚规范](../../hardware/PINOUT.md)。默认采集固件不启用气路，设备拒绝命令时界面会显示拒绝。

## 操作

1. 点击连接，等待设备信息查询完成。旧mock不支持命令时等待查询超时，再开始被动采集。
2. 真实称重在批次外进行空载去皮，再放置已知砝码并输入质量标定；等待设备报告完成。模拟标定只演示状态流程。
3. 填写批次、操作员、品种、产地和方案编号；通过“批次 / 标定 / SOP 档案”补充采摘条件、传感器型号批次、标定版本/日期/参考仪表/结果及 SOP 版本和文档位置。未知信息可空。档案可另存为带校验的 JSON 新版本，已有文件不会覆盖；载入档案和结束批次时清空初始装料质量，避免沿用上一批质量。点击开始批次后档案锁定。
4. 默认开始时、每30秒和关键事件拍照；模拟模式保存水印图片，真实模式默认使用相机0。批次外可点击“相机参数”选择编号、固定曝光及白平衡；空白保持驱动设置，数值使用DirectShow驱动单位。请求随批次保存，驱动读回随照片保存；拒绝请求或数值不一致时记失败，不声称已锁定。部分驱动不支持自动曝光状态读回，记为未知。
5. 点击摇青开始/结束、取样等记录事件。“师傅检查”打开观察表单，未判断保持空值；修订最近标签保留历史。
6. 如启动过气路，先点击停止气路并核对设备，再结束批次。等待保存队列及照片完成，查看检查报告。

**结束批次、断开或退出不等同于物理急停。** 动作命令不会在重连后自动恢复；超时表示结果未知，确认设备状态后断开并重新连接。停止气路命令不取消正在进行的称重标定。

## 数据与检查

数据写入`data/raw/<批次>/`：传感器、事件、图片索引、师傅标签、原始串口、命令、设备日志、元数据及检查报告。连接日志另存`data/device_logs/`，含批次外标定记录。运行数据默认不提交Git，应另行备份。

每批 `meta.yaml` 保存人工档案完整快照与 SHA256、初始设备配置及最新设备配置，配置变化另记健康日志。输入初始装料质量时使用该值计算失水；留空时使用首个正且有限的称重，并记录来源。标定档案是人工记录，不代表设备已完成标定或通过精度验收；固件/硬件身份、软件版本及设备来源由程序记录，人工档案不能覆盖。

真实相机在独立进程内打开/读取/编码，默认8秒超时后终止，下次拍照重新建立；关闭程序取消未完成照片并记录原因，批次结束正常等待照片完成或超时。图片文件仅由主进程写入，已终止的相机进程不会迟到写入旧批次。操作系统本身的磁盘阻塞不属于此相机超时机制的覆盖范围。

连接日志每16MiB换新段，同一软件日志会话最多64段（约1GiB）；到上限报告错误并停止当前批次，保留所有已有文件，归档后重启程序。不会自动删除原始实验日志；长期归档和剩余磁盘空间仍由操作人员管理。

运行中及失败批次带`INCOMPLETE`标记；成功收尾移除。`writer_summary.json`记录接收/写入/拒收/未写入数量。flush不保证断电零丢失。没有明确来源的旧串口数据标为`serial_unverified`，模拟数据不得用于实验结论。

```powershell
.\.venv\Scripts\python.exe session_check.py ../../data/raw/批次编号
.\.venv\Scripts\python.exe -m unittest discover -p "test_*.py" -v
```

## 历史回放与对比

点击“历史回放 / 对比”添加一个或多个批次目录，无需连接设备。选择气敏、质量、失水、温湿度等曲线；可按批次起点或第 N 次工艺事件对齐。缺少指定事件的批次会明确提示并从此次叠加中排除，不会悄悄换用另一事件。

拖动时间条、输入秒数或点击事件跳转；播放支持1/5/30/60倍速。当前选中批次的传感器值、最近事件、最近标签修订和照片跟随游标，均显示记录时间。所有标签历史保留，游标不会提前显示未来修订。照片采用游标之前最近一张，不表示精确同时曝光。

读取只生成内存快照，不修改批次文件。旧表缺失、缺图、缺列、时间倒退/无效和未完成批次会显示警告；优先统一使用主机单调时间，旧批次无该时间时使用带时区日期，不混合两种时钟。数据来源显示在批次名和图例中；模拟数据不能用于实验结论。数据读入内存，大批次的内存占用随文件大小增加。

## 实验工程分析与报告

在回放窗口点击“导出分析报告”，设置基线和稳定时间窗、指标及重复实验组，再选原始批次以外的输出目录。分析全部已添加批次，统一相对各自批次起点，独立于回放的事件对齐方式。也可运行：

```powershell
python analysis.py ../../data/raw/BATCH_A ../../data/raw/BATCH_B --output ../../data/reports --field gas_1_v --baseline 0 60 --stable 60 120 --repeat-group EXP01
```

结果保存至新的 `engineering-analysis-v1_时间_随机ID/`：`report.html`（汇总）、`report.json`（参数、输入SHA256、指标定义、原CSV记录索引）、`curves.csv`、`curves.png`。不会覆盖旧报告或原始批次，未完成批次拒绝导出；导出失败保留报告的 `INCOMPLETE` 标记。

窗口是半开区间 `[start,end)`，必须人工选择有实验含义的洁净空气基线/稳定段；程序不自动判断其科学有效性。默认排除除 `OK`/`SERIAL_GAP` 以外的质量标记、无效数值、重复时间和禁用通道。输出均值、样本标准差、最小二乘斜率、稳定均值与基线均值之差及失水曲线；无效或未定义指标为 `null`。原始记录不会被排除规则删除。

缺包只在MCU时钟连续段内按已见序号集合推测，迟到帧可填补缺号；重启/时钟回退证据、倒序、重复分别计数，不估计首尾丢包。重复性使用组内各批稳定均值的样本标准差/CV，仅在两批以上、人工确认同组、档案和来源一致且完整覆盖窗口时计算；模拟组只验证计算。未提供模型分类、品质结论或自动工艺建议。

## 人工滚筒控制

固定硬件方案、接线和实测前提见[DRUM-v0.1](../../hardware/MOTOR_BASELINE.md)。设备须使用motor构建并报告新遥测，旧固件不会启用启动按钮。选择5～30RPM、正/反转、1～300秒，点击“人工启动滚筒”；控制器接受不等于电机已经达到目标，核对带方向的编码器RPM。

停止后需反馈低于1RPM保持1秒才可重新启动/换向；故障需检查实物并手动复位，复位不会启动。退出、断线、GUI无响应或失去匹配心跳，固件按DRUM基准关闭输出。结束批次时先请求停止滚筒，等待静止遥测；5秒内无法确认则以INCOMPLETE收尾，须检查硬件状态。软件按钮不替代独立硬件急停，断电后可能仍有惯性滑行。

滚筒参数、起止设备时间、故障、反馈RPM和MOTOR_START/END事件保存到批次；`motor_current_a`无测量保持空值。回放和分析可选择目标/反馈RPM。模拟模式演示命令、心跳超时和数据流程，不验证PI、电机负载或实际安全链。

详细实现见[开发文档](DEVELOPMENT.md)，本轮测试见[验证记录](VALIDATION.md)，评分定义见[标签量表](LABEL_SCALE.md)。真实设备、独立安全链及至少8小时连续运行尚待验收。
