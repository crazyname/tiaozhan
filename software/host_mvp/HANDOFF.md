## 复验命令

```powershell
python -m unittest discover -s software/host_mvp -v
powershell -File hardware/esp32_s3_mvp/test/run_core_tests.ps1
pio run -d hardware/esp32_s3_mvp -e esp32s3 -e esp32s3_air -e esp32s3_motor
```
