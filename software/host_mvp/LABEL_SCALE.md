# 师傅观察量表草案

版本：`MASTER-SCALE-v0.1-draft`。供软件联调和观察记录，尚未通过师傅校准或观察者一致性验证。

| 字段 | 记录含义 | 1 / 3 / 5 的暂定锚点 |
|---|---|---|
| aroma_level | 主观香气强度，不是品质优劣 | 很低 / 中等 / 很高 |
| leaf_softness | 主观柔软程度 | 很低（偏硬）/ 中等 / 很高（偏软） |
| red_edge_level | 主观红边程度 | 很低 / 中等 / 很高 |
| water_loss_feeling | 主观失水感，不代替称重失水率 | 很低 / 中等 / 很高 |
| confidence | 对本条判断的主观信心，不是模型概率 | 很低 / 中等 / 很高 |

2和4表示相邻锚点之间。所有评分默认“未判断”，保存为空，不能当作0或3参与分析。阶段包括未判断、初始、摇青中、静置中、可杀青；下一步建议包括未判断、继续静置、开始摇青、停止摇青、开始杀青、取样。建议只记录，不触发执行器。

每条记录关联批次、检查事件、操作员、带时区时间和单调时钟。修订追加新记录并保留原值；revision递增、supersedes引用旧标签。取消表单不会删除已经发生的检查事件。

正式实验前由参与师傅共同确认参考样、观察条件和分级锚点；修改定义必须升级量表版本，不混用不同版本评分。
