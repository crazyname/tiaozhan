## 四份材料统一口径

- 项目名称统一为：`青韵智控——凤凰单丛做青多模态感知与自适应控制系统`；
- 参赛组别当前按官方模板中的 **农业绿色发展** 口径准备；若学校最终通知不同，以学校正式表格为准；
- 当前答辩展示阶段统一表述为：**实验室多参数感知、连续采集与数据追溯原型阶段**；已报测试数值和完整原始证据的差异，按答辩冻结单披露；
- 尚未获得的实验结果、专利、客户、营收、融资、应用证明，不写成已有成果；
- 核心技术表述统一为：**多模态感知 → 做青状态估计 → 工艺决策 → 执行 → 品质反馈**；
- 核心创新不写“电子鼻”“自动摇青机”本身，而强调多模态状态表征、跨批次稳定和状态驱动控制；
- 路演 PPT 不设置团队介绍正文页；团队和指导教师信息只在官方申报表需要时填写。

## 材料关系

```text
项目汇总表：统一人、项目、组别等基础信息
      ↓
作品申报书：把项目按官方申报字段正式登记
      ↓
作品说明书：完整证明“为什么做、做了什么、怎么验证、价值在哪”
      ↓
路演PPT：把说明书压缩成评委短时间内可理解的证据链
```

所有正式材料中的技术状态、项目进度和成果口径必须一致。
