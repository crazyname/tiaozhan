# P3｜1.1 项目背景

## 页面结论

**凤凰单丛品质形成高度依赖做青环节，但关键判断仍主要依靠经验。**

## 左：做青为什么关键

- 决定香气形成与风格表达；
- 影响叶缘红变、含水状态与回软节奏；
- 直接关系成茶品质稳定性。

## 中：当前主要问题

- 看不见：鲜叶真实状态缺少在线量化；
- 看不准：香气变化与经验判断难标准化；
- 控不稳：固定程序难适应天气、茶季与原料差异。

## 右：项目切入点

- 多模态感知；
- 状态估计；
- 自适应控制。

## 底部工艺链

`采青 → 晒青 → 凉青 → 做青 → 杀青 → 揉捻 → 烘焙`

重点高亮“做青”。

# P4｜1.2 现有自动化边界

## 页面结论

**现有自动化主要解决“会执行”，仍缺少对鲜叶状态的理解与动态响应。**

## 对比

### 已经可以做到

- 自动摇青；
- 固定程序控制；
- 温湿度监测；
- 单一电子鼻识别阶段；
- 机器视觉提取色泽。

### 仍然缺少

- 多源状态联合表征；
- 跨天气、茶季、批次稳定；
- 状态进入工艺决策闭环；
- 以成茶品质验证控制效果。

## 页底句

> 做青自动化 ≠ 做青智能化。

# P5｜2.1 项目总体架构

## 页面结论

**构建“感知—估计—决策—执行—反馈”的完整做青闭环。**

## 主流程

1. 多模态感知：VOC、视觉、叶温、失水率、环境；
2. 状态估计：阶段、香气、失水、红变、置信度；
3. 工艺决策：是否摇、摇多重、摇多久、静置多久；
4. 执行控制：滚筒/电机/参数输出；
5. 品质反馈：感官、理化、批次稳定性。

建议用一张横向系统架构图占据页面核心。

# P7｜3.1 多模态感知

## 页面结论

**单一气味信号难完整描述鲜叶状态，多模态用于重构老师傅的综合判断。**

## 五类输入

- VOC：气味响应指纹；
- RGB：色泽、红变、纹理和形态；
- 失水率：质量和失水速率；
- 叶温：热湿状态；
- 环境：温湿度与工艺历史。

## 关键验证

后续必须通过消融实验比较：

`仅 VOC → VOC+环境 → VOC+视觉 → VOC+失水/叶温 → 全模态`

# P8｜3.2 电子鼻工程化

## 页面结论

**电子鼻真正的难点不是“能不能响应”，而是能不能在真实湿热环境和不同批次下稳定工作。**

## 主要问题

- 湿度干扰；
- 基线漂移；
- 老化；
- 器件差异；
- 吸附残留与恢复时间。

## 工程措施

- 固定采样流量；
- 独立清洗气路；
- 动态基线；
- 温湿度补偿；
- 周期参考校准；
- 跨批次归一化。

## 边界表述

不声称低成本 MOS 精确测量单一香气分子浓度，定义为“综合色体响应指纹”。

# P9｜3.3 状态估计

## 页面结论

**把多源信号转化为可解释、可复核的做青状态，而不是只输出黑箱分类结果。**

## 输入

VOC + RGB + 失水 + 叶温 + 环境 + 工艺历史

## 输出

- 当前阶段；
- 香气发展水平；
- 失水状态；
- 红变程度；
- 综合状态指数；
- 模型置信度。

## 方法策略

优先使用适合小样本、可解释的方法：PCA/PLS、LDA、Random Forest、XGBoost、轻量 MLP、简单时序模型。

## 验证规则

必须按批次划分训练/验证/测试，避免同批数据泄漏。

# P10｜3.4 自适应控制

## 页面结论

**从 Time-based 控制，转向 State-based 控制。**

## 左：固定程序

`到时间 → 固定转速 → 固定时长 → 固定静置`

问题：难适应不同天气、茶季和原料状态。

## 右：状态驱动闭环

`实时感知 → 状态估计 → 参数决策 → 执行反馈 → 再感知`

## 动态决定

- 什么时候摇；
- 摇多重；
- 摇多久；
- 静置多久；
- 什么时候结束做青。

# P11｜3.5 技术创新与方案对比

## 页面结论

**创新不在“多一个传感器”，而在于把多模态状态表征真正接入工艺决策闭环。**

建议采用横向能力矩阵比较：

- 传统人工；
- 固定程序自动化；
- 单一电子鼻识别研究；
- 青韵智控目标方案。

比较维度：

- 自动执行；
- VOC 在线感知；
- 视觉/失水融合；
- 跨批次校准；
- 状态驱动控制；
- 成茶品质闭环。

正式稿所有“有/无/优于”必须有文献、产品资料或实验依据。

# P12｜4.1 分阶段验证路线

## 页面结论

**先证明“测得准”，再证明“判断对”，最后证明“控制有效”。**

## 阶段 1：在线监测

传感稳定、数据同步、真实做青被动采集。

## 阶段 2：人工确认半自动

系统给建议，师傅确认后执行。

## 阶段 3：自适应闭环

状态驱动工艺参数，系统形成闭环。

严禁在前两阶段数据不足时提前宣称已实现闭环有效。

# P13｜4.2 A/B/C 对照与品质验证

## 页面结论

**闭环是否成立，最终必须回到独立批次的成茶品质与稳定性。**

## A/B/C

A：老师傅传统做青

B：固定程序自动做青

C：状态驱动自适应做青

## 三类评价

### 过程

关键节点判断、人工干预、参数轨迹。

### 品质

感官审评、含水率、VOC/GC-MS（条件允许）、理化指标。

### 工程

稳定性、数据完整性、人工参与时间、维护成本。

# P14｜5.1 应用价值与社会价值

## 页面结论

**不是替代制茶师傅，而是把可测、可复核的经验沉淀为数字工艺。**

## 价值 1：经验数字化

把香气、失水、色泽与工艺动作形成关联记录。

## 价值 2：降低经验断层

辅助年轻制茶人员理解关键状态变化。

## 价值 3：中小茶企渐进升级

外挂式感知和现有设备改造，降低数字化门槛。

## 价值 4：过程可追溯

原料、环境、动作、状态和成茶结果形成完整档案。
