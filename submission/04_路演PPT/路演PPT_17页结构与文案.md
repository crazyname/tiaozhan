## P3｜1.1 项目背景

页面结论：

> **凤凰单丛品质形成高度依赖做青环节，但关键判断仍主要依靠经验。**

左｜做青为什么关键：
- 决定香气形成与风格表达
- 影响叶缘红变、含水状态与回软节奏
- 直接关系成茶品质稳定性

中｜当前主要问题：
- 看不见：鲜叶真实状态缺少在线量化
- 看不准：香气变化与经验判断难标准化
- 控不稳：固定程序难适应天气、茶季与原料差异

右｜项目切入点：
- 多模态感知
- 状态估计
- 自适应控制

底部工艺链：

`采青 → 晒青 → 凉青 → 做青 → 杀青 → 揉捻 → 烘焙`

高亮“做青”。

---

## P4｜1.2 现有自动化边界

页面结论：

> **现有自动化主要解决“会执行”，仍缺少对鲜叶状态的理解与动态响应。**

已经可以做到：
- 自动摇青
- 固定程序控制
- 温湿度监测
- 电子鼻阶段识别
- 机器视觉提取色泽

仍然缺少：
- 多源状态联合表征
- 跨天气 / 茶季 / 批次稳定
- 状态进入工艺决策闭环
- 以成茶品质验证控制效果

页底：

> **做青自动化 ≠ 做青智能化**

## P5｜2.1 项目总体架构

页面结论：

> **构建“感知—估计—决策—执行—反馈”的完整做青闭环。**

主流程：
1. 多模态感知：VOC、视觉、叶温、失水率、环境
2. 状态估计：阶段、香气、失水、红变、置信度
3. 工艺决策：是否摇、摇多重、摇多久、静置多久
4. 执行控制：滚筒 / 电机 / 参数输出
5. 品质反馈：感官、理化、批次稳定性

## P7｜3.1 多模态感知

页面结论：

> **单一气味信号难完整描述鲜叶状态，多模态用于重构老师傅的综合判断。**

五类输入：
- VOC：气味响应指纹
- RGB：色泽、红变、纹理、形态
- 失水率：质量和失水速率
- 叶温：热湿状态
- 环境：温湿度与工艺历史

关键验证：

`仅 VOC → VOC+环境 → VOC+视觉 → VOC+失水/叶温 → 全模态`

必须通过消融实验验证多模态增量。

---

## P8｜3.2 电子鼻工程化

页面结论：

> **电子鼻已证明“能稳定响应”，下一步重点验证湿热环境、气路和跨批次条件下能否保持稳定。**

已取得的基础工程证据：
- 4 个有效通道对凤凰单丛样品均产生可重复响应
- 响应幅度：39.16%–67.36%
- 响应时间：58.6–97.4 s
- 重复性平均 CV：6.18%
- 最大 CV：8.19%
- 短期基线漂移：3.73%

仍需解决：
- 湿度干扰
- 气路流量一致性
- 清洗恢复
- 长周期漂移与老化
- 器件 / 批次差异

工程措施：
- 固定采样流量
- 独立清洗气路
- 动态基线
- 温湿度补偿
- 周期参考校准
- 跨批次归一化

边界：
> 当前数据证明低成本 MOS 阵列具备重复响应和工程采集能力，不代表已经完成做青阶段识别，也不声称单一 VOC 定量浓度。

## P9｜3.3 状态估计

页面结论：

> **把多源信号转化为可解释、可复核的做青状态，而不是只输出黑箱分类结果。**

输入：

`VOC + RGB + 失水 + 叶温 + 环境 + 工艺历史`

输出：
- 当前阶段
- 香气发展水平
- 失水状态
- 红变程度
- 综合状态指数
- 模型置信度

方法策略：
- PCA / PLS
- LDA
- Random Forest / XGBoost
- 轻量 MLP / 简单时序模型

规则：
- 按完整批次划分训练 / 验证 / 测试
- 低置信度回退人工确认

## P10｜3.4 自适应控制

页面结论：

> **从 Time-based 控制，转向 State-based 控制。**

固定程序：

`到时间 → 固定转速 → 固定时长 → 固定静置`

状态驱动：

`实时感知 → 状态估计 → 参数决策 → 执行反馈 → 再感知`

动态决定：
- 什么时候摇
- 摇多重
- 摇多久
- 静置多久
- 什么时候结束做青

第一代控制：

> **状态估计 + 规则约束 + 人工确认**
